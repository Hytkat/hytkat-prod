# Hytkat portfolio
1. `cp .env.example .env` and fill it in (Spotify keys, SPOTIFY_ARTIST_ID, YOUTUBE_CHANNEL_ID)
2. `npm install && npm run dev`
3. Edit `src/data.ts`: snippets (audio in `public/audio`), previous work (images in `public/work`), extra Spotify links, hidden titles.
4. Releases are cached for an hour in `.cache` (delete it to refresh).
